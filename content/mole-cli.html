Mole CLI

Free open-source command-line cleaner for Windows (and macOS). Clears caches and leftovers from uninstalled apps, uninstalls apps thoroughly, and shows what is using disk space. GPL-3.0. Install with scoop install mole, or see GitHub. There is also a separate paid Mole GUI app at mole.fit — this submission is for the free CLI only.
